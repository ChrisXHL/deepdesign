# GitHub 语言风格系统 · Voice & Tone

> **一句话人格**：一个欢迎所有开发者"回家"的乐观伙伴。它说 `GitHub is where you belong.`——把冷冰冰的代码托管，讲成一种归属感。

GitHub 文案融合**开发者同侪的务实**与**温暖的归属感/乐观主义**，还爱玩一点开发者才懂的文字游戏（`Dependencies you can depend on.`）。母语为**英文**。下方例句保留官网英文原文。

---

## 一、人格轴

| 维度 | 取值 | 说明 |
|---|---|---|
| 疏离 ↔ 归属 | **归属** | `call GitHub home` / `where you belong`。 |
| 悲观 ↔ 乐观 | **乐观** | `build the technologies that shape what's next`。 |
| 严肃 ↔ 巧思 | **带文字游戏** | `Dependencies you can depend on.` |
| 泛泛 ↔ 务实 | **务实** | 每个能力配真实数字与客户故事。 |
| 精英 ↔ 包容 | **包容** | "无论你是在扩张还是刚学写代码"。 |

---

## 二、语气基调

- **把工具讲成归属**：`Millions of developers and businesses call GitHub home.` / `GitHub is where you belong.`——归属感是主旋律。
- **面向"下一个"的乐观**：`Change is constant. GitHub keeps you ahead.` / `build the technologies that shape what's next.`
- **开发者内行文字游戏**：`Dependencies you can depend on.` / `Your secrets, your business.`——同一个词玩两层意思，懂的人会心一笑。

---

## 三、人称与句式

- **对读者**：`you / your team`，包容地把新手和资深都算进来。
- **自称**：`GitHub` 作主语（"GitHub keeps you ahead" / "GitHub keeps your team's conversation next to your code"）。
- **招牌句式——祈使短句作小标题**：`Plan with clarity.` / `Work together, achieve more.`
- **前提句 + 转折**：`Change is constant. GitHub keeps you ahead.`——先立事实，再给产品的位置。

---

## 四、遣词偏好

**爱用**
- 归属词：home、belong、together、community
- 乐观词：ahead、what's next、shape、achieve more
- 开发者双关：depend on、your secrets your business、push protection
- 务实数字：70% MTTR reduction、8.3M secret leaks stopped

**禁用（一出现就破功）**
- ❌ `synergy`、`enterprise-grade solution`（干巴巴的企业腔）
- ❌ 精英式、排他式表达（GitHub 要包容新手）
- ❌ 空洞形容词最高级
- ❌ 感叹号轰炸

---

## 五、Do / Don't

✅ **Do**
- 把产品讲成"开发者的家 / 归属"
- 用面向未来的乐观语气
- 在合适处玩一个开发者才懂的双关
- 每个能力配真实数字或客户故事

❌ **Don't**
- 不要写成排他的精英俱乐部
- 不要用干巴巴的企业黑话
- 不要靠形容词自夸
- 不要忘了新手也是读者

---

## 六、真实例句（github.com 官网原文）

- **归属**：`Millions of developers and businesses call GitHub home.` / `GitHub is where you belong.`
- **定位**：`Change is constant. GitHub keeps you ahead.`
- `Work together, achieve more.` / `Plan with clarity.`
- **双关**：`Dependencies you can depend on.` / `Your secrets, your business.`
- **务实**：`70% MTTR reduction with Copilot Autofix.`

---

## 七、改写示例（AI 腔 → GitHub 腔）

**产品定位**
- ❌ AI 腔：`The industry-leading enterprise-grade platform that empowers developers to maximize their coding productivity.`
- ✅ GitHub 腔：`Millions of developers and businesses call GitHub home.`

**安全功能**
- ❌ AI 腔：`Our advanced security features help you protect your sensitive credentials and dependencies effectively.`
- ✅ GitHub 腔：`Dependencies you can depend on. Your secrets, your business.`

**中文版（沿用同一套语气：归属感 + 乐观 + 一点巧思）**
- ❌ AI 腔：「业界领先的企业级开发平台，全面赋能开发者，最大化提升编程效率。」
- ✅ GitHub 腔：「几百万开发者，把 GitHub 当家。变化不停，GitHub 让你始终领先一步。」
